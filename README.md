# ⚡ Red de IA Disruptiva y Multi-Agente (Python + Streamlit + Gemini)

Sistema web interactivo y distribuido construido con Python, Streamlit y la API oficial de Google GenAI, diseñado para procesar retos complejos mediante una red colaborativa de múltiples agentes de Inteligencia Artificial (`gemini-3.8-flash`).

## 🌟 Características de la Red Multi-Agente

1. 🧠 **Nodo 1 (Agente Estratega):** Analiza disruptivamente el objetivo principal, desglosando los pilares fundamentales y el enfoque inicial del proyecto.
2. 💻 **Nodo 2 (Agente Tecnológico):** Toma la estrategia previa para diseñar la propuesta técnica detallada o arquitectura de software necesaria.
3. 🛡️ **Nodo 3 (Agente Auditor):** Evalúa de forma crítica la viabilidad, detecta riesgos potenciales y entrega un veredicto optimizado.

## 🛠️ Tecnologías Utilizadas

* **Python**
* **Streamlit** (Interfaz web interactiva)
* **Google GenAI SDK** (`google-genai`)
* **Modelo Gemini** (`gemini-3.8-flash`)
